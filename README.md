# Two Values Easy Calculation Program

# 1. Introduction

In the mini project, I built the program to calculate two values with the operator including Addition, Subtraction, Multiplication, Division and another operator.

# 2. How program work?

In the program. You will insert two values and the operator to calculate two values with the operator. If you select Addition, the first value adds the second value into the summary of two values.

# 3. Result

The summary of two values and the operator from functions.
